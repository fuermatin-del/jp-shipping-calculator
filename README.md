# 日本 FBM 运费核算

面向亚马逊日本站发货的静态运费核算网页。输入包裹长、宽、高、实际重量及日本收件地区后，页面展示各渠道报价、计费重量、附加费和计算过程，并从可推荐的渠道中选出最低价。

## 当前范围

- 盛欣仅使用 3661 佐川普货渠道；其他盛欣渠道不参与当前报价。
- 报价规则以 `app.js` 中的 `channelRules` 为准，`日本FBM运费模板.xlsx` 是便于核对和维护的静态规则表。修改表格不会自动更新网页，价格变更需同步修改 `app.js` 并运行测试。
- OCS 偏远或超范围派送邮编需要在网页中单独选择，不能只凭都道府县判断。
- 盛欣 3661 冲绳偏远费以日元报价，网页报价时请求 JPY/CNY 汇率；若汇率获取失败，该费用标记为需人工确认。
- 缺少完整计费规则的渠道仅显示“需人工确认”，不参与最低价推荐。页面报价不包含未明确提供的税费、清关费等实际账单项目。

## 本地使用与发布

直接打开 `index.html` 可使用网页。发布到 GitHub Pages 时，将 `index.html`、`app.js`、`styles.css` 和本文件放在仓库根目录，并在仓库 Settings → Pages 中选择从 `main` 分支的 `/ (root)` 发布。更新价格后，先运行 `node shipping-rules.test.js`，再上传更新后的文件；浏览器仍显示旧价格时请强制刷新。
